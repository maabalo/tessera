    # readme

    What is Tessera?

    Tessera makes QR codes: square barcodes a phone camera can read. Choose what the code holds, style it, and download it as a PNG image or an SVG file. Everything happens in your browser: nothing is uploaded.

    01 Quick start

    1. Pick a type in 01 content: link, Wi-Fi, contact, email, phone or SMS.
    2. Fill in the fields. The preview updates as you type.
    3. Change colors and shape in 02 style if you like, and add a center symbol (a built-in icon or your own logo).
    4. Click png or svg to download, or copy to paste it somewhere.
    5. Test it with your phone's camera before you print or share it.

    02 What each type does when scanned

    link / text
    A link opens in the browser. Other text is shown on screen.
    wi-fi
    Offers to join the network. No need to type the password.
    contact
    Offers to save a new contact with the details you entered.
    email
    Opens a new email to that address, with the subject and message filled in.
    phone
    Offers to call the number.
    sms
    Opens a text message to the number, with your message filled in.

    Open what's inside the code under the preview to see the exact text.

    03 Making codes that always scan

    • Size: print it at least 2 cm (0.8 in) wide, and bigger for long text or far-away scanning (about 1/10 of the scanning distance).
    • Contrast: dark code on a light background works everywhere. Light-on-dark doesn't.
    • Margin: keep the blank border (4 modules) unless the background is plain and light.
    • Error correction: M suits most uses. Choose H for printed codes that may get scratched or dirty. Higher levels make the code denser.
    • Center symbol: it covers part of the code, so Tessera switches to level H while it's shown. Use rounded or square modules with a symbol on long codes; dots with a symbol only scan reliably on short ones. On very long codes (about 470+ characters), skip the symbol.
    • Shorter is better: less text means bigger squares, which scan faster. Use a short link where you can.
    • Scan check: in browsers with a built-in barcode reader (such as Chrome), Tessera reads every code back and tells you if it worked.

    04 Files

    png
    An image for documents, slides, websites and messages. Pick the size in 02 style.
    svg
    A vector file that stays sharp at any size. Best for print and design tools.
    copy
    Copies the PNG image so you can paste it into a document or chat.

    05 Privacy

    • The codes are made on your device. Nothing you type is sent anywhere.
    • Your last content and style are remembered in this browser, so they're back next time.
    • The Wi-Fi password is never saved. Type it again when you come back.
    • An image you add as a center symbol is shrunk to 256 px and remembered in this browser only.
